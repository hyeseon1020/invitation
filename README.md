# 💌 Mobile Invitation Web Application

> **PHP & MySQL 기반 1인 개발 모바일 초대장 웹 애플리케이션**  
> 사용자가 손쉽게 모바일 초대장을 생성 및 관리하고, 하객/참석자가 편리하게 정보를 확인하고 참석 여부를 전달할 수 있도록 제작된 프로젝트입니다.

---

## 🗓️ 개발 일정
* **1차 개발 기간**: 2026.02.02 ~ 2026.02.21

---

## ✨ 주요 기능 (Key Features)

### 🛠️ 관리자 기능 (Admin)
- **초대장 생성 및 관리**: 이름, 날짜, 시간, 장소(주소), 제목, 인사말 설정
- **이미지 관리**: 갤러리 사진 등록, 대표 이미지 지정, 사진 표시 순서 변경
- **QR 코드 생성**: 모바일 접근성을 높이기 위한 초대장 전용 QR 코드 생성
- **참석자 통계**: 하객/참석자 응답 데이터를 파악할 수 있는 통계 기능

### 📱 초대장(사용자) 주요 기능
- **갤러리**: 등록된 사진을 모바일 화면에 최적화된 형태로 제공
- **지도 연동**: 행사장 위치를 직관적으로 확인할 수 있도록 카카오/네이버 등 지도 API 연동

---

## 🛠️ Tech Stack

- **Backend**: PHP 8.x, MySQL
- **Frontend**: HTML5, CSS3, JavaScript (AJAX)

---

## 📁 프로젝트 구조 (Directory Structure)

```text
├── admin/          # 관리자 페이지 (초대장 생성, 통계, 관리)
├── ajax/           # 카테고리 및 테마 처리를 위한 비동기 AJAX 통신
├── assets/         # CSS, JS, 이미지 및 테마 관련 정적 파일
├── config/         # DB 연결 및 공통 설정
├── public/         # 하객용 메인 페이지 및 참석자 체크 로직
├── Checklist.php   # 주요 기능 체크리스트 및 테마 관련 처리
└── index.php       # 애플리케이션 진입점
```
---

### 💡 주요 변경 사항
1. **시각적 구조화**: 헤더, 배지, 구분선을 추가하여 가독성을 극대화했습니다.
2. **기능 세분화**: 관리자 기능과 하객/사용자 기능을 나누어 프로젝트 전체 범위를 한눈에 파악할 수 있게 정리했습니다.
3. **디렉토리 구조 명시**: 기존 리포지토리의 주요 폴더(`admin`, `ajax`, `assets`, `config`, `public`)의 역할을 한 줄 설명으로 명시하여 코드를 둘러보는 사용자에게 명확한 가이드를 제공합니다.
